本页面汇总了从基础软件向插件发送的通知事件。

关于PLUGIN/2.0本身的通信规范等内容，请参阅PLUGIN/2.0的相关页面。

[NOTIFY]显示的事件，一定会通过NOTIFY命令进行通知。
即使将脚本返回给通过NOTIFY命令通知的事件，也会被完全忽略。

未特别显示的事件，根据具体情况，可能会以NOTIFY或GET方式之一进行通知。

PLUGIN Event

version

在插件加载后立即触发。
插件会针对该事件，在Value头部返回插件的版本信息。
通过Charset头部指定字符编码后，即可为后续请求指定使用的字符编码（默认值为Shift_JIS）。
请注意，其响应格式与其他事件不同。

installedplugin

列举已安装的插件并进行通知。[NOTIFY]

Reference*
以字节值为单位，依次为插件名称、插件ID
installedghostname

列举已安装的人格并发送通知。[NOTIFY]

Reference0
以字节值为单位分隔的人格名称列表
Reference1
以字节值为单位分隔的\0名称列表
Reference2
以字节值为单位分隔的\1名称列表
installedballoonname

列举已安装的Balloon并发出通知。[NOTIFY]

Reference0
以字节值分隔的Balloon名称列表
ghostpathlist

正在读取的人格文件夹的路径。[NOTIFY]

Reference*
正在读取的人格文件夹的完整路径。
若指定了多个文件夹，可能还存在Reference1及后续项。
balloonpathlist

正在读取的Balloon文件夹的路径。[NOTIFY]

Reference0
正在读取的Balloon文件夹的完整路径。
headlinepathlist

正在读取的头条文件夹路径。[NOTIFY]

Reference*
正在读取的头条文件夹的完整路径。
pluginpathlist

正在读取的插件文件夹的路径。[NOTIFY]

Reference*
正在读取的插件文件夹的完整路径。
OnSecondChange

经过数秒后发生。
每隔几秒通知一次，可在descript.txt的secondchangeinterval中进行设置。

OnOtherGhostTalk

当人格说话时触发。
可在descript.txt的otherghosttalk中进行设置。

Reference0
人格名称。
Reference1
人格的本体侧名称。
Reference2
若中断对话，则为break。
若进行交流，则为communicate。
若为SSTP SEND，则为sstp-send。
若为Owned SSTP，则为owned。
若为非本地SSTP，则为remote。
若指定不进行翻译，则为notranslate
如果是来自插件的脚本，则为plugin-script
如果是来自插件的事件响应，则为plugin-event
返回的内容以逗号分隔。
Reference3
人格所提及的事件ID。
Reference4
人格所提及内容的脚本。
Reference5
以字节值1分隔、传递给人格的Reference。
OnGhostBoot

在人格启动时发生。

Reference0
以字节值为单位，表示已启动的人格中\0之后各角色窗口的HWND。
在未构建等情况时，可能会出现0。
Reference1
已启动的人格名称。
Reference2
已启动的人格当前的Shell名称。
Reference3
已启动的人格的ID（与Owned SSTP所发送的一致）。
Reference4
已启动的人格的完整路径。
OnGhostExit

在人格结束时发生[NOTIFY]

Reference0
以字节值为单位，表示已结束的人格中\0之后各角色窗口的HWND。
在未构建等情况时，可能会出现0。
Reference1
已结束的人格名称。
Reference2
已结束的人格当前的Shell名称。
Reference3
已结束的幽灵的ID（与通过Owned SSTP发送的相同）。
Reference4
已结束的幽灵的完整路径。
OnGhostInfoUpdate

当人格的信息发生变更时触发。
在加载时也可能触发。[NOTIFY]

Reference0
以字节值为单位，表示发生变更的人格中\0之后各角色窗口的HWND。
在未构建等情况时，可能会出现0。
Reference1
发生变更的人格名称。
Reference2
发生变更的人格当前的Shell名称。
Reference3
发生变更的人格的ID（与通过Owned SSTP发送的相同）。
Reference4
发生变更的人格的完整路径。
OnMenuExec

当从右键菜单中执行插件时触发。
建议采取某种响应措施。

Reference0
以字节值为单位，表示调用插件的人格中\0之后各角色窗口的HWND。
在未构建等情况时，可能会出现0。
Reference1
调用插件的人格名称。
Reference2
调用插件的人格当前的Shell名称。
Reference3
调用插件的人格ID（与Owned SSTP中发送的相同）。
Reference4
调用插件的人格的完整路径。
OnInstallComplete

在完成某项安装时触发。

Reference0
以字节值为单位，表示安装类型。
Reference1
以字节值为单位，表示已安装软件的名称。
Reference2
以字节值为单位，表示已安装软件的完整路径。
在OnChoiceSelect(Ex)/OnAnchorSelect(Ex)/\q等中指定的任意名称事件

在选项与锚点选择时触发的 SHIORI Event 的插件侧钩子。
当插件向人格发送的脚本以及插件向人格通知的事件所对应的人格回复脚本中，包含选项或锚点类的Sakura脚本标签时，在该次操作中，与在SHIORI侧因选项或锚点选择而触发的通知事件相同，也会以旁路通知的形式同步传递至插件端。

Reference*
触发的选项或锚点类SHIORI事件的Reference。
在\![raiseplugin]和\![notifyplugin]中指定的任意名称事件

由\![raiseplugin]和\![notifyplugin]执行时触发。
对于\![notifyplugin]而言[NOTIFY]

Reference*
指定的任意参数。
property.get

pluginlist(插件名称/路径/ID).ext在获取扩展属性时发生。
返回已获取的属性值。

Reference0
扩展属性的名称。

pluginlist(插件名称/路径/ID).ext在设定扩展属性时发生。
成功时返回204，失败时返回适当的状态码。

Reference0
扩展属性的名称。
Reference1
应设置的值。
