概要

这是用于人格更新系统（网络更新）的更新定义文件的规范。
更新定义文件中记录了构成人格的文件列表及其哈希值，基础软件会从服务器获取该列表，并与本地文件进行比对，从而执行差异更新。

目前有效的格式仅有以下两种。旧格式updates.dau（版本1）已废弃，故予以省略。

updates2.dau (版本2)
以字节值分隔的、偏向二进制的格式。
updates.txt (版本3)
以字节值分隔，但带有行前缀的文本格式。

updates2.dau (版本2)

以单个字节值作为字段分隔符，每行以CRLF结尾的格式。

字符编码

默认使用操作系统默认的字符集。可以通过在首条条目的末尾附加 charset=字符编码名 字段来指定。

行格式

每行采用以下格式

文件路径\x01MD5哈希值\x01扩展字段1\x01扩展字段2\x01...

\x01 表示字节值1。换行符为CRLF。

示例

ghost/master/descript.txt\x01a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4\x01size=1234\x01date=2024-01-15T12:34:56\x01charset=Shift_JIS\x01
ghost/master/shiori.dll\x01f6e5d4c3b2a1f6e5d4c3b2a1f6e5d4c3\x01size=65536\x01date=2024-01-15T12:34:56\x01
shell/master/surface0.png\x01deadbeefdeadbeefdeadbeefdeadbeef\x01size=32768\x01date=2024-01-15T12:34:56\x01

※ \x01 实际对应字节值 1。而charset= 仅附加在首条条目的末尾。

updates.txt (版本3)

与updates2.dau具有相同的字节值分隔，但每行都采用带有行类型前缀的文本格式。

行类型

各行根据行首前缀来确定类型。不以file, 或 charset, 开头的行将被忽略。

charset,字符编码名
指定后续各行的字符编码。请在文件开头附近进行描述。
file,数据集...
file, 前缀之后的内容与updates2.dau采用相同的格式。

示例

charset,Shift_JIS
file,ghost/master/descript.txt\x01a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4\x01size=1234\x01date=2024-01-15T12:34:56\x01
file,ghost/master/shiori.dll\x01f6e5d4c3b2a1f6e5d4c3b2a1f6e5d4c3\x01size=65536\x01date=2024-01-15T12:34:56\x01
file,shell/master/surface0.png\x01deadbeefdeadbeefdeadbeefdeadbeef\x01size=32768\x01date=2024-01-15T12:34:56\x01

※ \x01 实际上是一个字节值1。

字段详细信息

updates2.dau和updates.txt的 file, 行中是共通的字段定义。

必填字段
文件路径 (位置[0])
更新对象文件的相对路径。以斜杠 (/) 分隔。
MD5哈希值 (位置[1])
文件内容的MD5哈希值。32位十六进制字符串。
扩展字段 (位置[2]之后)

键=值 格式描述。全部可省略。

size=数值
文件大小（以字节为单位）。
date=字符串
ISO 8601格式的日期时间字符串。例如: 2024-01-15T12:34:56
charset=字符串
文字编码名。仅附加于updates2.dau文件首条记录的末尾。仅用于字符编码判定，作为定义文件读取时会被忽略。

路径处理

URL编码

如果所有条目均已进行百分号编码，则对其进行解码后使用。否则，仅对URL部分进行编码。

安全检查

符合以下条件的条目被视为无效。

  • 没有MD5。
  • 末尾为 / 或 \（目录条目）。
  • 包含..\ 或 ../ （用于防止目录遍历攻击）。

生成处理

借助SSP的“更新文件创建”功能等，可从人格的文件列表中生成updates2.dau / updates.txt。

文件扫描

递归遍历目录。以下文件将被排除。

  • 隐藏文件 (FILE_ATTRIBUTE_HIDDEN)
  • developer_options.txt 中的 noupdate 所指定的文件
  • 被.gitignore格式的过滤文件排除的文件
复制到ghost\master

如果目录根下存在 ghost\master 文件夹，则将生成的更新文件也复制到其中。
