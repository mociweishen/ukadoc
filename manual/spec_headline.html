前书

HEADLINE/2.0是旧有规范（1.1）的修订版。目前仅在SSP中实现。

主要变更在于新增了字符编码的指定。

头条正文

需要两个文件：配置文件“descript.txt”和用于导出 execute 函数的 DLL 文件。

DLL

请参阅DLL页面。

请求-响应 1：获取版本

request示例

GET Version HEADLINE/2.0
Charset: UTF-8
Sender: SSP

request头部详情

Charset
字符编码
Sender
事件发送方

response示例

HEADLINE/2.0 200 OK
Charset: UTF-8
Value: HeadlineModule 1.1

response头部详情

Charset
[可省略]字符编码。省略时采用调用方指定的编码。
Value
[可省略]版本字符串

请求-响应 2：获取标题

request示例

GET Headline HEADLINE/2.0
Charset: UTF-8
Sender: SSP
Option: url
Path: C:\SSP\temp\ad9326dc37cb86a9.html

request头部详情

Charset
字符编码
Sender
事件发送方
Option
[可省略]响应中可解析的选项，以逗号分隔列举。
目前仅支持url。请参阅response的Headline头部项。
Path
标题解析的目标文件路径（完整路径）。

response示例

HEADLINE/2.0 200 OK
Charset: UTF-8
Headline: 巴拉巴拉1
Headline: 巴拉巴拉2
Headline: 巴拉巴拉3
Headline: 巴拉巴拉4
Headline: 巴拉巴拉5

response头部详细

Charset
[可省略]字符编码。省略时采用调用方指定的编码。
RequestCharset
[可省略]下次调用时希望使用的字符编码。若省略，则使用Charset。
Headline
标题的内容。
当调用时，若Option头部中包含类似“Option: url”的内容，则已支持URL扩展。
在这种情况下，以字节为单位逐段返回，响应格式为“内容[1]URL”，这样人格也能接收到URL；如果人格端也支持相应功能，点击该条目后即可跳转至详细页面等操作。
此外，返回的并非Sakura脚本的片段，且不能使用标签，仅返回纯文本。

descript.txt

请参阅Headline设定页面。

SHIORI Event

有关详情请参阅SHIORI Event页面。

OnHeadlinesenseBegin
头条感知开始时。
OnHeadlinesense.OnFind
当有需要朗读的内容时。
OnHeadlinesenseComplete
头条感知正常结束时。
OnHeadlinesenseFailure
头条感知失败时。

补充

GET Headline会被调用两次。第一次针对旧文件，第二次针对新文件。但请注意，从旧到新的顺序在某些实现中可能会颠倒，因此请勿编写依赖于特定顺序的处理逻辑。

在调试等情况下，若希望始终显示（不出现“no update”提示），请在 descript.txt 中写入 alwaysdisplay,1（调试结束后务必删除）。
