surfacetable.txt

概要

用于SSP开发人员界面中的“surface 测试”功能，以及旨在配合其他的壳体创建辅助工具使用的表面内容定义文件。

基本的格式

示例

charset,UTF-8
version,1
option,DisableNoDefineSurfaces

//==========零件==========
group,__disabled
{
	19,__parts
}

//==========空==========
group,[空]平日
{
	scope,0
	
	0,素
	1,害羞
	3,不安
	4,嗯~
	5,笑
}

以//开头的行被视为注释，将被完全忽略。

可使用半角空格和制表符进行缩进。

surfacetable.txt

charset,字符编码

要显示的字符编码。务必写在文件的第一行。

Shift_JIS

version,数值

surfacetable.txt的格式版本。目前始终为1即可。

1

option,选项1,选项2,...

可选参数。可用逗号分隔，支持多列列举。
目前仅支持指定“DisableNoDefineSurfaces”，即忽略那些既未在surfaces.txt等文件中定义、也未在surfacetable.txt中明确列出的表面。

无任何行为

group,组名

为下文所述的表面名称定义行所组成的组别赋予一个识别名称。
紧接下方，连续写上只有“{”的行，并用只有“}”的行闭合。
若将组名设为“__disabled”，则表示该组内的表面未被使用（在SSP的surface测试中将不再显示于列表中）。

无任何行为

scope,数值

该组的曲面主要所属范围的编号。
在组内仅填写一项。
本体侧为0，搭档侧为1等。

无任何行为

表面ID,名称

为表面ID赋予一个用于识别的名称。
通常应将其写入普通组内。
在组内最先被写入的内容，将被视为该组的标准表面（例如，scope,0表示0，scope,1表示10等）。
若将名称设为“__parts”，则表明该表面主要用于作为动画、换装等的部件（在SSP的surface测试中，该名称被视为未指定）。
在省略名称的情况下，可以明确表示该名称尚未定义。在SSP的表面测试中仅针对特定表面即使未指定也会赋予初始值，因此当希望取消对这类表面的指定时可加以使用。

无任何行为/在SSP的urface测试中，仅针对特定表面标准表面定义。
