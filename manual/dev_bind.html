设置换装

换装

在伪春菜的Shell中可以设置换装（有关换装本身的说明，请参阅“Shell - surfaces.txt”中的“换装（MAYUNA）”）。

通过使用换装功能，当从右键菜单中进行选择时，便可在同一个Shell内切换或开启/关闭角色外观的某些部分。

在SSP模式下也可以通过SAKURA脚本的指令来切换装扮。

换装仅在MATERIA和SSP中可用，而在CROW中仅显示初始装扮配置。

不过，由于MATERIA的Bug，只有\0侧会显示换装菜单。

因此，包括\1在内，实际上只有SSP实现了完整的功能。

此外，本页面的说明以用户对动画设置本身已有一定了解为前提。

关于动画设置，请参阅“制作Shell”页面中的“编写surfaces.txt - 动画篇”一节。

surfaces.txt的设置

surface0
{
animation0.interval,bind
animation0.pattern0,add,100,0,0,0
animation0.pattern1,add,101,0,20,35
animation0.pattern2,reduce,102,0,0,0
animation0.pattern3,add,103,0,0,0
}

根据上述内容，在interval中指定了bind的动画将成为换装效果。

关于add、reduce等绘图方法将在后文详述。

权重虽被指定为0，但当interval用于bind动画（即换装）的设置时，无论权重指定为何值都将被忽略。

X坐标与Y坐标的偏移位置指定，可像普通动画模式一样进行设置。

此外，animation0中的数字“0”是动画的ID，而在换装场景下，这个ID尤为重要。

关于换装的绘制方法

在本家伺か中，换装基本上都是通过bind、add、reduce、insert这四种方法来实现的。

而在SSP中，除了上述方法外，base、overlay、overlayfast、replace、interpolate、asis等方法也可以与普通动画通用。

不过，不能使用start、stop、move等并非单纯进行图像合成的方法。

descript.txt的设定

在descript.txt中进行的操作，简而言之，就是为了将换装功能显示在右键菜单的换装选项中而做的准备工作。

具体写法如下。

sakura.bindgroup0.name,服装,围裙式连衣裙,apron.png
sakura.bindgroup1.name,缎带,白色缎带,ribbonwhite.png
sakura.bindgroup2.name,服装,黑色服装,black.png
sakura.bindgroup3.name,缎带,黑色缎带,ribbonblack.png

sakura.bindgroup0.default,1
sakura.bindgroup1.default,1

kero.bindgroup0.name,领带,领带
kero.bindgroup1.name,臂章,黑色臂章
kero.bindgroup2.name,手臂,钻头

kero.bindgroup0.default,1
kero.bindgroup1.default,1

sakura.menuitem0,2
sakura.menuitem1,3
sakura.menuitem2,-
sakura.menuitem3,0
sakura.menuitem4,1

kero.menuitem0,0
kero.menuitem1,1
kero.menuitem2,-
kero.menuitem3,2

通过如上所述的描述，可在角色本体侧的换装菜单中添加“围裙式连衣裙”、“黑色服装”、“白色丝带”、“黑色丝带”

在搭档侧的菜单中将出现“领带”、“臂章”和“手臂”，玩家可以自由地为其穿戴或卸下。

?.bindgroup*应按从左至右的顺序，以逗号分隔填写类别名、部件名和缩略图文件名。

此时“bindgroup*”中的*数字，需与surfaces.txt中设定的换装动画ID相对应。

因此，请注意，在所有表面上，相同的服装（换装）必须被赋予相同的动画ID。

?.bindgroup*.default 将动画ID为“*”的换装设置为该壳体换装的初始值。

在上述设置中，默认情况下为围裙裙与白丝带、领带与黑臂章。

指定0或省略时，将处于换装关闭状态。

?.menuitem*,* 表示菜单项的结构。

按照菜单显示顺序分配编号，并用逗号分隔，指定 bindgroup* 中对应编号（请注意，此处指定的并非动画ID）。

如果用“-”代替bindgroupID，将在菜单中的该位置显示一条分隔线。

在上述示例中，主体侧的换装菜单将按从上到下的顺序依次显示黑色服饰、黑色丝带、（分隔线）、围裙式连衣裙、白色丝带。

缩略图将作为菜单选择时的参考显示。

不如无需使用，可省略；但在换装数量较多，或名称难以让人联想到具体换装内容时，指定该信息会更为方便。
