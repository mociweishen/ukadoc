descript.txt

descript.txt（Plugin的）

概要

插件的基本配置文件。

示例与基本写法

charset,UTF-8
name,假插件
id,21AC84B0-6B1F-11E4-9803-0800200C9A66
filename,rei.dll

name、id、filename为必填项。

此外，以\或%开头的字符串将被视为樱花脚本或环境变量的标记，并出于安全考虑被丢弃。如果希望将其作为普通字符包含，请使用\\或\%等方式进行转义。

charset,字符编码

使用的字符编码。考虑到与旧环境的兼容性时，请使用Shift_JIS；其他情况建议使用UTF-8。

（操作系统的默认设置或SSP→I18N:国际化设置→默认字符集→文本定义）

name,插件名称

该插件的名称。

不可省略

id,ID

作为该插件的ID，应尽可能选择重复可能性极低的字符串。
字符串必须由单字节字符组成，且长度不超过63个字节。通常使用所谓的GUID/UUID。
一旦确定后便不得更改。
ID匹配指示即使是别名插件也是兼容的。

※生成方法http://www.famkruithof.net/uuid/uuidgen。
或者在开发环境较为完善的情况下，也可以使用guidgen.exe的注册表(Registry Format)格式。
工具也已发布。

不可省略

filename,dll

插件所对应的DLL文件的路径。

不可省略

type,种类

文件集的类型。如果是插件，则为plugin。

无值

craftman,作者名

该插件的作者姓名。仅限半角英数字。

无值

craftmanw,作者名

该插件的作者姓名。

无值

craftmanurl,URL

插件作者的网址。

无值

homeurl,URL

用于网络更新的URL。

无值

readme,文件名

安装时打开的插件说明文本文件名。

readme.txt

readme.charset,字符编码

说明文本文件的字符编码。

（操作系统的默认设置或SSP→I18N:国际化设置→默认字符集→readme）

  • 2.5.10
secondchangeinterval,秒数

PLUGIN Event OnSecondChange的触发间隔（秒）。
设为0时将不再触发通知。

1

otherghosttalk,选项

PLUGIN Event OnOtherGhostTalk的启用设置。

false
不通知
0
不通知
true
即时通知（说完后立即通知）
1
即时通知
after
即时通知
before
直前通知（在说话前的即时通知）

false
