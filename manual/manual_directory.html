整体结构

人格与Shell

人格的配置文件被放置在基础软件（SSP、materia等）的人格存储文件夹中。

所有人格都必须拥有一份主人格和一个主Shell。

从Shell的角度来看，每个Shell都必然归属于某个人格。

因此，两者的文件结构将如下所示，其中 Shell 被包含在人格中。

+-(myghost)
　　+-ghost
　　　　+-master
　　　　　　+-descript.txt
　　　　　　+-shiori.dll
　　　　　　+-makoto.dll
　　　　　　+-updates2.dau
　　　　　　+-*.ico
　　　　　　+-*.cur
　　+-shell
　　　　+-master
　　　　　　+-descript.txt
　　　　　　+-surface*.png
　　　　　　+-surface*.pna
　　　　　　+-(element).png
　　　　　　+-(element).pna
　　　　　　+-surfaces.txt
　　　　　　+-makoto.dll (仅在需要时)
　　　　　　+-menu_background.png
　　　　　　+-menu_foreground.png
　　　　　　+-menu_sidebar.png
　　　　　　+-readme.txt (仅在需要时)
　　　　　　+-thumbnail.png
　　　　　　+-surfaces**.txt (仅限SSP)
　　　　　　+-surfacetable.txt (仅在需要时)(仅限SSP)
　　　　　　+-alias.txt (仅在需要时)(旧规格)
　　　　+-(additional_shell)
　　+-delete.txt (仅在需要时)
　　+-delete1.txt (delete[数字].txtも追加で認識できる)
　　+-developer_options.txt (仅在需要时)(仅限SSP)
　　+-.narignore (仅在需要时)(仅限SSP)
　　+-.updateignore (仅在需要时)(仅限SSP)
　　+-.narinclude (仅在需要时)(仅限SSP)
　　+-.updateinclude (仅在需要时)(仅限SSP)
　　+-readme.txt 或 readme.md (仅在需要时)
　　+-terms.txt 或 terms.md (仅在需要时)
　　+-thumbnail.png

Balloon

气球并非按人格单独管理，而是统一归于基础软件进行统筹，并在所有人格之间共享。

每个气球的配置文件均按照如下方式放置于基础组件的气球存储文件夹之下。

+-(myballoon)
　　+-descript.txt
　　+-balloons*s.txt
　　+-balloonk*s.txt
　　+-readme.txt または readme.md (仅在需要时)
　　+-terms.txt または terms.md (仅在需要时)
　　+-balloons*.png
　　+-balloonk*.png
　　+-balloons*.pna （MATERIA不可）
　　+-balloonk*.pna （MATERIA不可）
　　+-balloonc*.png
　　+-online*.png
　　+-sstp.png
　　+-arrow*.png
　　+-thumbnail.png
　　+-ok_down.png/ok_up.png （仅限SSP）
　　+-cancel_down.png/cancel_up.png （仅限SSP）
　　+-mode_down.png/mode_up.png （仅限SSP）
　　+-sstp_new.png （仅限SSP）
　　+-marker.png （仅限SSP）
　　+-delete.txt (仅限SSP・仅在需要时)
　　+-delete1.txt (也能额外识别 delete[数字].txt)
(myghost)\

各人格的主目录（根目录）。

建议使用英数字命名文件夹。

(myghost)\ghost\

用于人格内部运行的文件夹。

(myghost)\ghost\master\

人格默认使用的文件夹。

目前仅使用master（为历史设计遗留）。

有关Ghost文件夹内文件结构的详细信息，请参阅“人格”页面。

关于makoto.dll，请参阅“翻译器”页面。

(myghost)\shell\

用于存放人格Shell（图形显示文件）的文件夹。

(myghost)\shell\master\

默认Shell的文件夹。必选。

(myghost)\shell\(additional_shell)\

附加Shell的文件夹。可自定义名称（建议使用英数字）。

可以存在任意多个。存在时可在右键菜单等处进行切换选择。

有关Shell文件夹内文件结构的详细信息，请参阅“Shell”页面。

关于menu_background.png、menu_foreground.png、menu_sidebar.png，请参阅“右键菜单”页面。

关于makoto.dll，请参阅“翻译器”页面。

(myghost)\delete.txt

用于设置文件删除的配置文件。

详情请参阅链接页面。

可省略。

(myghost)\developer_options.txt

SSP专用。nar及更新文件创建功能的配置文件。

详情请参阅>链接页面。

可省略。

(myghost)\readme.txt 或 readme.md

整个人格的自述文件。

通常应明确注明发布者及来源等信息。

在第一行写上charset,UTF-8，或者包含BOM，这样就能使用Shift JIS以外的编码。

除安装时自动打开外，也可通过右键菜单等方式打开。

可省略，但最好存在。

可以使用readme.md代替readme.txt，此时会解析Markdown格式，并以带有字体大小、表格等装饰的方式显示。
也可以解析图片嵌入 \![图片说明](图片路径) ，但仅当图片路径为相对路径、人格中确实存在该文件且格式为PNG或JPEG时才可使用。

(myghost)\terms.txt 或 terms.md

利用条件表示。NAR/ZIP文件的安装前会弹出显示此内容的对话框。

会中断安装并显示对话框，因此仅在确实必要时才应启用。

与readme相同，只需在第一行写上charset,UTF-8，或包含BOM，即可使用Shift JIS以外的编码。

可省略，且若无需使用则建议省略。

terms.md也可按与readme.md相同的条件使用。

(myghost)\thumbnail.png

在菜单树中选择人格时显示的缩略图

可用的图像格式为png或jpg。

将png文件重命名为pnr时，图像左上角的1个像素点（坐标0,0）及其同色部分将被透明化。

可省略。

(myballoon)\

各BAlloon的主目录（根目录）。

建议使用英数字命名文件夹。

气泡文件夹内文件结构的详细说明请参见“Balloon”页面。
