SHIORI Resource

SHIORI Resource的原型，是在旧协议SHIORI/2.5中定义的一种请求，用于获取所有者绘制菜单的显示内容以及 homeurl 等简单字符串信息的请求。
通过此规范，您可以根据人格端的状态来控制这些信息。

在 SHIORI 3.0 及更高版本中，由于对旧规范的整理，它在实现上已与普通的 SHIORI Event 并没有明确区分。

与常规SHIORI事件的不同之处在于，其返回值并非Sakura脚本，而仅以（简短的）文本形式处理（包括类似布尔值的内容）。此外，请求ID并不以“On”开头，且英文字母均采用小写表示。

SHIORI信息

以下4个ID的请求通常由SHIORI自动回复，各人格作者方均不予理会。

version

在SHIORI加载完成后立即触发。
SHIORI会针对此事件返回SHIORI的版本信息（而非SHIORI协议的版本）。

craftman

在SHIORI加载完成后立即触发。
SHIORI会针对此事件返回SHIORI的作者名。仅允许使用7位字符。

craftmanw

在SHIORI加载完成后立即触发。
SHIORI会针对此事件返回SHIORI的作者名。除7位字符外，还可使用8位字符以及默认编码下的多字节字符。

name

在SHIORI加载完成后立即触发。
SHIORI会针对此事件返回SHIORI的名称（而非人格名称）。仅支持7位字符。

log_path

在操作开发面板中的“打开”时触发。返回指向 SHIORI 日志文件的完整路径。
另请参阅SHIORI Event : enable_log。

getaistate

AI图表的SHIORI/3.0版。
绘制关于人格内部状态（对话次数、好感度等）的雷达图。
按以下格式返回。

图表显示值组 [字节值1] 图表标签组 [字节值1] 图表累加值组 [字节值1] 图表最大值组

图表显示值组
请以半角数字、逗号分隔的形式返回您希望在图表中显示的数值。
自2.4.26版本起支持小数点后位数。
图表标签组（可省略）
请以逗号分隔的形式返回您希望在图表中显示的标签。
省略时：Neuron,NeuronM,NeuronK,NeuronD,NeuronE,Synapse
图表加算值组（可省略）
请以半角数字、逗号分隔的形式返回图表中的“加算值”。
自2.4.26版本起支持小数点后位数。
加算值是指一种用于突出显示学习过程中增加的数值或最近发生变化的数值等功能，并将其加到图表显示值中进行呈现。
省略时：全部置为零并隐藏
图表最大值组（可省略）
请以半角数字、逗号分隔的形式返回图表的最大值。最大值 ≥（显示值 + 增加值）。
自2.4.26版本起支持小数点后位数。
省略时：计算显示值与增加值之和，并将该最大值设置为所有要素的值

例如：1250,1500,45,65,19500,4[b1]馬力,rpm,km/h,t,kgf,軸[b1]100,50,40,0,0,1[b1]1350,1550,130,96,20000,8
[b1]表示字节值1。

工具提示类

tooltip

获取Shell中工具提示的内容。
当鼠标光标悬停在Shell的表面上时发出通知。
Shell侧设置存在时，以该设置为准。

Reference0
鼠标光标的 x 坐标（局部坐标）
Reference1
鼠标光标的 y 坐标（局部坐标）
Reference2
始终为0。
Reference3
本体时为0，搭档时为1。在SSP/CROW中还有2及以上的情况。
Reference4
碰撞检测的标识符。
Reference5
始终为0。
balloon_tooltip

获取Balloon选项上的工具提示内容。
当鼠标光标悬停在选项上时发出通知。

Reference0
选项的文本（标签）。
Reference1
选项的ID。
Reference*
扩展信息（\q标签内的第三个及以后的参数）。
