解决错误信息

エラーメッセージの解消

在开发过程中，有时会遇到SSP抛出错误报告。
在这里，我们列举了一些有助于解决错误信息的参考信息。
这并非一份能够彻底解决问题的说明书，但相信会提供一些小小的提示。

目录

  1. ～ 不存在。
  2. 有人提到了旧定义与新定义的问题

～ 不存在。

这是最常出现的错误。大多数情况下，只需修正动画ID的拼写错误或定义遗漏等问题即可轻松解决，但也有一些情况需要费心处理。

[GHOST]default(master) shell 不存在。

根据伺か的规范，shell/master文件夹是必不可少的，否则将引发兼容性问题。
不过，如果实在不想创建master shell，也可以通过以下定义来规避。

seriko.defaultsurfacedirectoryname

[SERIKO]Surface=0(或10) 不存在。

在伺卡的规范中，0号和10号表面属于特殊处理，当使用\s标签指定不存在的编号时，它们会作为替代显示的“默认表面”。
即便0号尚可理解，但若不想创建10号表面，想必也有相应的理由，因此请尝试添加如下定义。

sakura.seriko.defaultsurface

kero.seriko.defaultsurface

char*.seriko.defaultsurface

有人提到了旧定义与新定义的问题

“明明在使用旧定义，却使用了新的定义方式”
“明明在使用新定义，却使用了旧的定义方式”
遇到诸如此类的错误信息时，请查看以下内容。”

descript - version

SERIKO的旧定义与新定义

在某些情况下，只需将以下内容追加到surfaces.txt文件的最上方，有时便可消除错误。

descript
{
version,1
}
