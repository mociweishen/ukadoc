安装

关于制作分发用压缩包的方法，请参阅“制作分发文件”页面。

Ghost通常以nar为扩展名的压缩包进行分发（也就是Nanika ARchive）。

nar只是将zip的扩展名改了一下，其本质仍是zip格式，因此在某些服务器上也可能以zip格式分发。

虽然使用lzh格式且具备解压DLL的情况下也能安装，但除非有特别充分的理由，否则不建议使用。

在SSP中，即使使用cab文件或自解压exe文件，也基本可以完成安装。

虽然也可以解压归档后手动安装，但如果已妥善准备了install.txt文件，通过拖放等方式即可触发安装程序功能，实现自动安装。

可通过将包含install.txt的Ghost文件夹拖放到基础软件（SSP）主程序中来创建nar。

这与手动压缩并重命名的zip文件效果相当，但此时需注意不要使文件夹层级过深。

在分发人格时，请注意不要将人格与Shell文件夹中的profile文件夹以及存档数据等一并包含在内

网络更新也同样适用。

在SSP中，为了实现这一控制，提供了developer_options.txt。

对于标准的人格
+-(myghost)
　　+-ghost
　　+-shell
　　+-install.txt
　　+-developer_options.txt (仅限SSP)
　　+-readme.txt
　　+-thumbnail.png
　　:
　　:

supplement的情况下，上述内容的の文件夹结构保持不变，仅将要添加的文件打包成压缩包。

例如，如果想将dic_supplement.txt这个文件添加到ghost/master/目录下

+-(mysupplement)
　　+-install.txt
　　+-developer_options.txt (仅限SSP)
　　+-ghost
　　　　+-master
　　　　　　+-dic_supplement.txt

则会变成这样。

对于标准的Shell
+-(additional_shell)
　　+-install.txt
　　+-developer_options.txt (仅限SSP)
　　+-descript.txt
　　+-readme.txt
　　+-thumbnail.png
　　+-surface*.png
　　+-surfaces.txt
　　:
　　:
对于标准的Balloon
+-(myballoon)
　　+-install.txt
　　+-developer_options.txt (仅限SSP)
　　+-descript.txt
　　+-balloonc*.png
　　+-balloons*.png
　　+-balloonk*.png
　　:
　　:
若将气球等物品与人格一同包装时
+-(myghost)
　　+-install.txt
　　+-developer_options.txt (仅限SSP)
　　+-ghost
　　+-shell
　　+-(myballoon)
　　　　+-descript.txt
　　　　+-balloons0.png
　　　　:
　　　　:

插件等也是如此（如果要随附Shell，不必这样做，直接将其放置在shell文件夹下即可）。

另外，作为随附方（如上述Balloon）无需提供install.txt文件，即使存在也会被忽略。

SSP专用）多实例安装包
+-(mypackage)
　　+-install.txt (package用)
　　+-(myghost1)
　　　　+-install.txt (myghost1用)
　　　　+-developer_options.txt (仅限SSP)
　　　　+-ghost
　　　　+-shell
　　　　:
　　+-(myghost2)
　　　　+-install.txt (myghost2用)
　　　　+-developer_options.txt (仅限SSP)
　　　　+-ghost
　　　　+-shell
　　　　:

请注意，用于打包的文件与单独的内容文件各自需要单独的install.txt文件。

不仅限于ghost，任何可单独打包的文件都可以一并包含；但针对shell、supplement等特定类型的文件，应注意不要混入其他不同类型的文件。

此外，对于头条传感器、插件单独分发等情况，也请在最上层目录中放置install.txt文件。
install.txt

用于记载安装设置的文本。

若无此文件，则基于拖放等的自动安装功能将无法运行。

用于设定归档内容类型、归档名称、目录名等信息。

详情请参阅链接页面。

developer_options.txt

仅限SSP。可省略。

与install.txt置于同一目录。

不过，对于用于多重安装的软件包，请注意不要使用最顶层的install.txt文件，而应将其放置在各个内容对应的install.txt所在位置。

在SSP中制作nar时，用于设置不包含在目标中的文件等信息的配置文件。

有关格式等详情，请参阅链接页面。
